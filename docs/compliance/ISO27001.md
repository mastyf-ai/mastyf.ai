# ISO 27001:2022 Compliance Mapping

mastyf.ai maps to the following ISO 27001 Annex A controls.

## A.5 — Organizational Controls

| Control | Description | mastyf Implementation |
|---------|-------------|----------------------|
| A.5.1 | Policies for information security | YAML policy engine — version-controlled, auditable security policies |
| A.5.8 | Information security in project management | Pre-install scanning (`@mastyf_ai/preflight`) for supply chain security |
| A.5.36 | Compliance with policies, rules, and standards | Audit hash chain with cryptographic integrity verification |

## A.8 — Technological Controls

| Control | Description | mastyf Implementation |
|---------|-------------|----------------------|
| A.8.1 | User endpoint devices | Cross-harness protection (Claude Code, Cursor, Codex, Gemini) |

| A.8.12 | Secure coding | Response scanning, DLP redaction, semantic result review |
| A.8.16 | Monitoring activities | Prometheus metrics + OpenTelemetry tracing + SIEM export |
